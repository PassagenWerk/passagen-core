# Passagen Core

`passagen-core` contains the shared domain, storage, provider, processing, and catalog services used
by `passagen-cli` and `passagen-web`.

It intentionally provides no command-line or HTTP entrypoint. Install `passagen-cli` for the
`passagen` command, or `passagen-web` for the local web interface.

Shared design, architecture, operations, and roadmap documents are indexed in
[`docs/README.md`](docs/README.md).
